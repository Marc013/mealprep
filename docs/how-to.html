AI Instructies — How-To

Hoe gebruik je de Copilot AI-instructies in dit project optimaal?
Overzicht van alle commando's, agents, skills en regels.

⚡ Quick Reference — Welk commando gebruik ik?
/mealplan-genereren   → Nieuw weekplan aanmaken
/maaltijd-aanpassen   → Maaltijd wijzigen op basis van feedback
/plan-valideren      → Macro's en consistentie controleren
/ingredient-toevoegen → Nieuw product toevoegen aan ingredients.json
/website-bijwerken   → GitHub Pages site synchroniseren na planwijziging
/github-pages-scaffold → Eerste opzet van de website (eenmalig)
💡

Typ het slash-commando in de GitHub Copilot Chat in VS Code (Agent Mode). Je hoeft de agent niet handmatig te selecteren — het commando koppelt automatisch aan de juiste agent.

📋 Slash Commands — Gedetailleerd overzicht
/mealplan-genereren
Genereert een volledig nieuw weekschema met 4 maaltijden (Ontbijt 10:15, Lunch 13:00, Mealprep1 15:45, Mealprep2 18:30) inclusief training- en rustdagvarianten, macro's per ingredient, Macros_Dagtotalen.md en Boodschappenlijst.md.
Optioneel: geef voorkeur mee, bijv. "gebruik meer kip" of "vermijd avocado"
Agent: MealplanAgent
/maaltijd-aanpassen [wat + welke maaltijd]
Past één maaltijd aan op basis van je feedback. Verplichte updateketen: (1) receptaanpassing → (2) herberekening maaltijdmacro's → (3) update Macros_Dagtotalen.md → (4) update Boodschappenlijst.md → (5) validatiesamenvatting.
Bijv.: "Mealprep1 — vervang rijst door zoete aardappel" of "Lunch — minder vet, meer eiwit"
Agent: MealplanAgent
/plan-valideren [plannummer]
Valideert het gehele actieve plan: macro's per maaltijd, dagtotalen (trainingsdag én rustdag), ingrediëntconsistentie, boodschappenlijst en structuurcontrole. Geeft een rapport met ✅/❌/⚠️ per categorie.
Bijv.: "plan9" of leeg laten voor het meest recente plan
Agent: MealplanAgent
/ingredient-toevoegen [productnaam]
Zoekt voedingswaarden op via voedingswaardetabel.nl, maakt een correct record aan en voegt dit in op de juiste alfabetische positie in src/ingredients.json. Synchroniseert metadata en valideert het bestand automatisch.
Bijv.: "Griekse yoghurt 0% Lidl" of "Quinoa Jumbo"
Agent: MealplanAgent
/website-bijwerken
Leest de maaltijdbestanden van het actieve plan, regenereert docs/data/meals.json en controleert of de website de data correct toont. Gebruik dit na elk nieuw plan of aanpassing.
Optioneel: geef het plannummer mee
Agent: GitHubPagesAgent
/github-pages-scaffold
Genereer de volledige GitHub Pages website (docs/) met het brutalist/industrial design. Gebruik dit eenmalig bij eerste opzet of na een complete redesign.
Beschrijf het doel: bijv. "meal prep tracker met macro-overzicht"
Agent: GitHubPagesAgent
🖥️ Hoe gebruik je dit in VS Code?

  1. Open GitHub Copilot Chat in VS Code (Ctrl+Alt+I of via de sidebar).

  2. Zorg dat je in Agent Mode zit — klik op het dropdown naast het invoerveld en kies Agent.

  3. Typ een slash-commando, bijv. /mealplan-genereren. Copilot laadt automatisch de bijbehorende agent (MealplanAgent) en de skill (mealplan/SKILL.md).

  4. Voeg optionele instructies toe na het commando, bijv. /maaltijd-aanpassen Mealprep2 — vervang kip door gehakt.

  5. De agent leest de benodigde bestanden (promp.md, src/ingredients.json, actief plan), berekent en valideert, en schrijft de outputbestanden direct naar de workspace.

  6. Na elke planwijziging: gebruik /website-bijwerken om de GitHub Pages site synchroon te houden.

⚠️

Let op Agent Mode: Slash commands werken alleen in Agent Mode, niet in de gewone chat. Controleer het dropdown-menu linksboven in het chatvenster.

📊 Macro-limieten — Strikte bovengrenzen
🏋️ Trainingsdag
Calorieën ≤ 2900 kcal
Eiwit ≤ 190 g
Vet ≤ 60 g
Koolhydraten ≤ 400 g
😴 Rustdag
Calorieën ≤ 1880 kcal
Eiwit ≤ 190 g
Vet ≤ 80 g
Koolhydraten ≤ 100 g
Shake-blok (vast — beide shakes + fruit)
Elke dag: 07:30 + 21:15 shake 535 kcal / 79g P / 6g V / 38g KH
🔴

Nul-tolerantie: kcal, vet en koolhydraten zijn absolute maxima. De AI mag ze nooit overschrijden, ook niet met 1g. Eiwit mag beperkt boven target als dit verzadiging verbetert.

🔄 Typische Workflows
Scenario A — Nieuw weekplan genereren

  1. Open Copilot Chat in Agent Mode

  2. Typ /mealplan-genereren (optioneel met specifieke wensen)

  3. Agent genereert alle bestanden in meals/planX/

  4. Typ /plan-valideren voor een kwaliteitscheck

  5. Typ /website-bijwerken om de site te synchroniseren

Scenario B — Maaltijd aanpassen op basis van feedback

  1. Typ /maaltijd-aanpassen Mealprep2 — te weinig groente, voeg courgette toe

  2. Agent past het recept aan, herberekent macro's, updatet Macros_Dagtotalen.md en Boodschappenlijst.md

  3. Agent geeft een validatiesamenvatting met dagtotalen en grenscheck

  4. Typ /website-bijwerken

Scenario C — Nieuw ingredient opzoeken en toevoegen

  1. Typ /ingredient-toevoegen Tempeh Jumbo

  2. Agent zoekt voedingswaarden op via voedingswaardetabel.nl

  3. Agent voegt het record toe op alfabetische positie in src/ingredients.json

  4. Agent valideert het JSON-bestand automatisch
